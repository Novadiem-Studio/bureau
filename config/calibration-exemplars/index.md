# Calibration Exemplars

This directory is the voice/texture reference library used by the article pipeline.

Most exemplars are local-only because they contain copyrighted excerpts, transcripts, found human writing, or Robin's own private writing. They can stay on this machine, but they should not be committed to a public repo.

## Public Rule

Only public-domain exemplars belong in git.

- Put public-domain material under `config/calibration-exemplars/public-domain/`.
- Keep all other exemplar files local. `.gitignore` ignores them by default.
- Use short attributed excerpts or pointers, not full copied works, unless the source is clearly public domain and the use is intentional.

## Local Buckets

The local library may still use audience buckets such as:

- `technical-builder`
- `founder-vision`
- `consumer-warm`
- `conscious-community`
- `professional-client`

For public commits, this index records the policy only. The private source list stays local.
