# Designer handoff — Visual System v2 poster family

**For:** designer / image-gen commissions  
**Canon:** `VISUAL-SYSTEM.md` · `VISUAL-CANON.md` · `LORE.md`  
**Public site:** material language only — `novadiem.com/docs/brand-brief-sacred-instrument.md`

**Commission order:** THE CURRENT → THE HUB → THE ENGINE → Build Party companion. **THE FRONTIER** (proposed IV) — after trilogy ships.

**Do not merge** pieces in one prompt.

---

## Shared material language

| Role | Value |
|------|-------|
| Field | Deep Instrument `#0B1020` |
| Panel | Night Panel `#141C2E` |
| Current / trace | Circuit Cyan `#3ECFCF` |
| Labels / rules | Filament Gold `#C9A227` |
| Text | Soft White `#E8ECF4` |
| Muted | Panel Grey `#8B95A8` |
| Display type | Sora 600 |
| Label type | DM Mono 400–500, small-caps |

**Style formula:** TVA × Art Deco × 1939 World's Fair Futurism — monumental civic instrument, brass/bronze/enamel, Streamline Moderne, bright optimistic daylight or controlled dark exhibit lighting on deep field.

**Never:** fantasy RPG UI · BPMN · synthwave · neon noir · comic captions · tarot numerals · dark academia alchemical · character grid as party lineup (except ENGINE).

**Attach:** `reference/novadiem-emblem.svg` on HUB and ENGINE.

# I. THE CURRENT

**Subtitle:** FEATURE WORKFLOW  
**Format:** Horizontal ~16:9 or 2:1 exhibit panel  
**Character art:** None

## Composition checklist

- [ ] Left: **IDEA** entry node (lightbulb or intent glyph — abstract, not character)
- [ ] Full-width brass rail labeled **THE CURRENT OF INTENT** (cyan energy flowing continuously L→R)
- [ ] Stations drop from rail (not inline boxes on the rail): Analizer 2000 → Architect → DESIGN-MODEL CHECKPOINT → Challenger (round 1) → Cleric fork → Spellwright → Challenger (round 2)
- [ ] Exit right: **`prompts.md` — vetted & scoped** + subline *execute-plan builds from here* + faint ghost arrow *→ shipped work* (toward THE FRONTIER)
- [ ] Beneath rail: continuous **Conductor side-channel** pulsing to `log.md` · `state.json` — not a station box
- [ ] Cleric fork: NOT NEEDED bypass to Spellwright; DESIGN REQUIRED path through brief → HUMAN HANDOFF → manifest
- [ ] Dashed red/gold return loops: Challenger findings → Conductor routes (max 2×) — no specialist-to-specialist arrows
- [ ] Legend strip: SPECIALISTS · CHECKPOINT · DESIGN HANDOFF · COLD REVIEWS · ARTIFACTS = MARKDOWN

## Composition

```

══════════════════════════════════════════════
          THE CURRENT OF INTENT
══════════════════════════════════════════════

THE ARCHITECT  (fit + chunk + coder assignment)
     ↓
THE CHALLENGER  (round 1)
     ↓
THE SPELLWRIGHT  (prompt folder: 00-index + NN-slug)
     ↓
THE CHALLENGER  (round 2)
     ↓
[ GATE ]  human approves prompt folder
     ↓
BUILD PARTY  (in order 01→NN)
  THE MAGE · THE SYSTEMSMITH · THE MECHANIC
     ↓ (each part)
THE CHALLENGER  (per-diff review)
     ↓
SHIPPED
```
